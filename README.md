# MLOps CI/CD: MLflow + Prometheus

## Мета роботи

Метою даної роботи є побудова та запуск повноцінного MLOps‑пайплайну з використанням **MLflow** для трекінгу експериментів та **Prometheus Pushgateway** для збору метрик навчання моделей.

У межах роботи було розгорнуто сервісну інфраструктуру в Kubernetes‑кластері та реалізовано скрипт навчання моделі з логуванням параметрів, метрик і артефактів.

---

## Архітектура рішення

Система складається з наступних компонентів:

- **MLflow** — сервер для трекінгу експериментів, зберігання метрик та моделей
- **PostgreSQL** — backend‑сховище для MLflow
- **MinIO** — S3‑сумісне сховище артефактів моделей
- **Prometheus Pushgateway** — прийом кастомних метрик з Python‑скрипта
- **Argo CD** — GitOps‑деплой усіх компонентів у Kubernetes

Усі сервіси розгорнуті в Kubernetes та синхронізуються через Argo CD з Git‑репозиторію.

---

## Скрипт `train_and_push.py`

Скрипт виконує наступні дії:

1. Завантажує датасет **Iris**
2. Навчає модель `LogisticRegression` з різними гіперпараметрами
3. Для кожного запуску:
   - логуються параметри
   - логуються метрики (`accuracy`, `loss`)
   - модель зберігається як MLflow artifact
4. Метрики `accuracy` та `loss` додатково надсилаються в **Prometheus Pushgateway**
5. Визначається та зберігається найкраща модель за accuracy

MLflow використовується як центральна точка спостереження за результатами навчання.

---

## Результати

- Успішно створено експеримент `iris-experiment`
- Виконано кілька запусків (runs) з різними гіперпараметрами
- Найкращий результат:

```
Accuracy ≈ 0.96
```

- Усі метрики та параметри відображаються в **MLflow UI**
- MLflow коректно працює з PostgreSQL та MinIO

## Висновки

У рамках роботи було:

- Налаштовано MLOps‑інфраструктуру в Kubernetes
- Реалізовано експериментальний ML‑пайплайн з MLflow
- Інтегровано Prometheus Pushgateway для збору кастомних метрик
- Продемонстровано повний цикл: навчання → логування → аналіз результатів

Отримане рішення демонструє базовий, але реалістичний приклад MLOps‑підходу з використанням сучасних інструментів.
